# DeepInterpolation: the scripts that were run

These three files denoise each trial movie before signal extraction (step 03 reads the
resulting `_dp.mat` files). They are a **vendored snapshot**, copied by hand rather than
generated by `tools/build_repo.py`, because their source is a git clone outside the lab
Dropbox tree.

## Provenance

Source: `https://github.com/mitchclough/deepinterpolation`, branch `sensorimotor`, a fork of
the Allen Institute's DeepInterpolation. The checkout used on the SCC was at commit
`9f4b377` (2023-02-08) **with uncommitted local modifications**: `inference_GPU_SCC.py`,
`create_json.py` and several other files differ from that commit, and
`deep_interpolation_scc_gpu_andrew.sh` was untracked (it sits in an `old scripts/` folder in
the checkout). The files here are the working-tree versions, which is what actually ran; the
commit hash alone does not identify them.

The fork also carries local edits to the package itself (`deepinterpolation/network_collection.py`).
The Allen Institute package is not redistributed here: its license is a 2-clause BSD plus a
clause restricting redistribution and commercial use.

## How it was run

Jobs were submitted on the BU Shared Computing Cluster:

```
qsub deep_interpolation_scc_gpu_andrew.sh <animal> <session>
```

The job requests one GPU (`gpu_c=7.0`), loads `miniconda` and the `tensorflow` module,
activates the `deepinterpolation` conda environment, and runs `inference_GPU_SCC.py`, which
reads the file list written by `create_json.py`.

## Model

Inference used `~/trained_model.h5` on the SCC (md5 `8318ba5481747463c256d74753e404cf`,
125,745,160 bytes, modified 2023-01-24). It is a transfer-trained network, distinct from the
two 2024 transfer models and from the Allen base model
`2019_09_11_23_32_unet_single_1024_mean_absolute_error_Ai148-0450.h5` that are also present in
the fork's `models/` folder. The weights are deposited with the data, at
`data/models/trained_model.h5`.

## Parameters

`SingleTifGenerator`, `pre_post_frame` 30, `pre_post_omission` 0, `batch_size` 5 (the
per-session path) or 1 (the chunked path used for long sessions), `randomize` 0. Output is
written next to each input as `<name>_dp.mat`.
